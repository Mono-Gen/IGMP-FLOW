### What the GPL-2.0 (Scapy) means for you

- **Running from source** (`python app.py`): you install Scapy yourself; this repository only contains MIT-licensed code that imports it.
- **Redistributing `IGMP-FLOW.exe`**: the executable contains Scapy, so the executable *as a whole* must be distributed under the
  terms of the GPL-2.0. Include [`licenses/Scapy-GPL-2.0.txt`](licenses/Scapy-GPL-2.0.txt) and make the complete corresponding source
  available (this repository, at the same version, satisfies that). MIT is GPL-compatible, so the combination is allowed.
- If you need a permissive-only binary, do not bundle Scapy (this would require replacing the capture/decoding layer).

## Not bundled: Npcap (required on Windows)

IGMP-FLOW captures packets through [Npcap](https://npcap.com/), which you must install separately. Npcap is **not** included in this
repository or in `IGMP-FLOW.exe`, and it has its own license: the free edition is limited (at the time of writing, a small number of
installs, no redistribution, with exceptions for Nmap/Wireshark use); commercial use at scale or redistribution requires the
paid Npcap OEM license. Read the current terms at <https://npcap.com/> before deploying IGMP-FLOW in an organization.
